## 1. 개요 (Overview)

기본정보기술자시험(基本情報技術者試験, FE) 합격의 당락을 결정짓는 **과목 B(科目B)** 대비 노트입니다.
과목 B는 **100분 동안 총 20문항**을 풀어야 하며, **알고리즘과 프로그래밍(16문항, 80%)** 및
**정보보안(4문항, 20%)**으로 구성됩니다. 문항당 평균 **5분 이내**에 코드를 트레이스(추적)하고 정답을
도출하는 실전 요령을 정리합니다.

## 2. IPA 과목 B 의사언어 (擬似言語) 핵심 문법 규격

실제 시험장에서 당황하지 않으려면 IPA 의사언어 고유의 표기법과 **1-based 인덱싱 규칙**을 완벽히
숙지해야 합니다.

### 2.1 변수 선언, 대입 및 연산자

```text
// 1. 변수 선언 및 초기화: '형식: 변수명 ← 초기값'
整数型: x ← 10                  // 정수형 변수 x에 10을 대입
実数型: rate ← 0.5              // 실수형 변수 rate에 0.5를 대입
論理型: flag ← true             // 논리형(불리언) 변수 flag에 true 대입

// 2. 1차원 배열 선언 (기본적으로 인덱스가 1부터 시작함에 주의!)
整数型の配列: arr ← {10, 20, 30, 40}
// arr[1]은 10, arr[2]는 20, arr[4]는 40 (문제 지문에 "要素番号は1から始まる" 명시됨)

// 3. 2차원 배열 접근: arr[행, 열]
整数型の二次元配列: matrix ← { {1, 2}, {3, 4} }
// matrix[1, 2]는 1행 2열의 값인 2를 의미함

// 4. 비교 및 논리 연산자
// 같다: = , 같지 않다: ≠ , 크거나 같다: ≧ , 작거나 같다: ≦
// 나눗셈의 몫: ÷ (정수 나눗셈 여부 확인), 나머지: mod
// 비트 연산: ∧ (AND), ∨ (OR), ⊕ (XOR), << (왼쪽 시프트), >> (오른쪽 시프트)
```

### 2.2 제어문 및 함수 표기법

```text
// [함수 정의 예시] 배열에서 특정 값을 찾는 선형 탐색 함수
○整数型: linearSearch(整数型の配列: data, 整数型: target)
  整数型: i
  // for 반복문: i를 1부터 data의 요소 수까지 1씩 증가시키며 반복
  for (i を 1 から dataの要素数 まで 1 ずつ増やす)
    // 조건문: if ~ elseif ~ else ~ endif
    if (data[i] = target)
      return i                  // 목표값을 찾으면 현재 인덱스(1-based) 반환
    endif
  endfor
  return -1                     // 찾지 못하면 -1 반환
```

> **실전 트레이스 꿀팁**: 문제에서 **"배열의 요소 번호는 1부터
> 시작한다(配列の要素番号は 1 から始まる)"**고 명시되어 있는지, 혹은 예외적으로 **`0`부터
> 시작**하는지 반드시 첫 줄에서 체크하고 시작해야 인덱스 오프바이원(Off-by-one) 실수를 막을 수
> 있습니다. {: .prompt-warning }

## 3. 과목 B 알고리즘 빈출 패턴 및 풀이 전략

### 3.1 이진 탐색 (二分探索, Binary Search)

정렬된 배열에서 탐색 범위를 절반씩 줄여가며 $O(\log N)$ 시간 복잡도로 값을 찾는 알고리즘입니다. 빈칸
채우기에서 `low`, `high`, `mid` 갱신 조건이 자주 출제됩니다.

```text
// 오름차순 정렬된 배열 arr에서 target의 인덱스를 반환하는 이진 탐색 의사코드
○整数型: binarySearch(整数型の配列: arr, 整数型: target)
  整数型: low ← 1               // 탐색 범위의 시작 인덱스 (1부터 시작)
  整数型: high ← arrの要素数     // 탐색 범위의 끝 인덱스
  整数型: mid                   // 중간 인덱스 저장용 변수

  // 탐색 범위가 유효한 동안 반복 (low ≦ high 조건 주의: 등호가 빠져선 안 됨)
  while (low ≦ high)
    mid ← (low + high) ÷ 2      // 중간 위치 계산 (정수 몫)
    if (arr[mid] = target)
      return mid                // 탐색 성공 시 인덱스 반환
    elseif (arr[mid] < target)
      low ← mid + 1             // 중간값보다 크면 오른쪽 절반 탐색 (mid + 1)
    else
      high ← mid - 1            // 중간값보다 작으면 왼쪽 절반 탐색 (mid - 1)
    endif
  endwhile

  return -1                     // 탐색 실패 시 -1 반환
```

### 3.2 단방향 연결 리스트 (単方向リスト, Singly Linked List)

클래스(또는 구조체) 참조를 이용해 노드를 삽입하거나 삭제하는 문제입니다. 포인터 연결 순서가 바뀌면
기존 노드의 참조가 유실되므로 **연결 순서**가 핵심 출제 포인트입니다.

```text
// 연결 리스트의 특정 위치(prevNode 뒤)에 새로운 노드(newNode)를 삽입하는 절차
○insertAfter(ListNode: prevNode, ListNode: newNode)
  // 1단계: 새 노드의 next가 기존 prevNode의 다음 노드를 먼저 가리키도록 연결
  newNode.next ← prevNode.next
  // 2단계: 그 후 prevNode의 next가 새 노드를 가리키도록 갱신
  prevNode.next ← newNode
  // (주의: 2단계를 먼저 실행하면 기존 prevNode.next 참조를 잃어버려 리스트가 끊어짐!)
```

### 3.3 재귀 호출 (再帰呼出し, Recursion) 및 트리 순회

자기 자신을 호출하는 함수는 작은 입력값(예: $n = 3$ 또는 노드 3~4개짜리 트리)을 대입하여 **호출
스택(Call Stack)이나 재귀 트리**를 시험지 여백에 직접 그려서 추적합니다.

- **전위 순회 (先行順, Pre-order)**: 부모 $\rightarrow$ 왼쪽 자식 $\rightarrow$ 오른쪽 자식
- **중위 순회 (中間順, In-order)**: 왼쪽 자식 $\rightarrow$ 부모 $\rightarrow$ 오른쪽 자식 (이진
  탐색 트리를 중위 순회하면 오름차순 정렬된 값을 얻음)
- **후위 순회 (後行順, Post-order)**: 왼쪽 자식 $\rightarrow$ 오른쪽 자식 $\rightarrow$ 부모
  (역폴란드 표기법 수식 계산에 활용)

## 4. 과목 B 정보보안 (情報セキュリティ) 4문항 공략법

과목 B의 마지막 4문항(17번~20번)은 정보보안 시나리오 문제입니다. 알고리즘 문제에서 시간이 부족해지지
않도록 **정보보안 4문항을 먼저 풀고 알고리즘 16문항으로 넘어가는 전략**도 매우 유효합니다.

### 4.1 주요 출제 시나리오 패턴

1. **웹 애플리케이션 취약점 대응**:
   - **SQL 인젝션**: 플레이스홀더(프리페어드 스테이트먼트, 바인드 변수) 사용으로 근본 차단.
   - **크로스사이트 스크립팅 (XSS)**: 사용자 입력값 출력 시 HTML 특수문자 이스케이프(새니타이징)
     처리.
   - **CSRF (크로스사이트 요청 위조)**: 요청 폼에 예측 불가능한 토큰(CSRF Token)을 포함하여 서버에서
     검증하거나 재인증 요구.
2. **네트워크 경계 및 클라우드 접근 통제**:
   - DMZ(비무장지대)에 공개 웹/메일 서버를 배치하고, 내부망 DB 서버는 DMZ의 웹 서버로부터의 특정
     포트 요청만 허용하도록 방화벽(FW) 정책 설계.
   - 클라우드 스토리지나 관리 콘솔의 접근 권한을 최소 권한 원칙(Least Privilege)과 IP 제한, 다중
     요소 인증(MFA)으로 통제.
3. **악성코드 감염 및 침해 사고 대응 (CSIRT)**:
   - 랜섬웨어 또는 표적형 공격(APT) 메일 감염 시 **네트워크 케이블 분리(격리)**를 통해 횡적
     확산(Lateral Movement) 및 C&C 서버 통신을 즉시 차단.
   - 포렌식 증거 보전을 위해 전원을 끄지 않고 메모리 덤프 및 감사 로그 확보.
