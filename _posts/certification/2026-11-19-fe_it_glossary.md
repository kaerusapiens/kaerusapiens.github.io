## 1. 개요 (Overview)

기본정보기술자시험(基本情報技術者試験, FE)을 준비하는 한국인 엔지니어가 가장 먼저 넘어야 할 장벽은
**일본어 한자 및 가타카나 IT 용어**입니다. 한국에서 쓰는 용어와 한자 표기가 다르거나 일본 특유의
가타카나 외래어로 표기되는 빈출 용어를 영역별로 정리하고 지속적으로 누적하는 사전입니다.

## 2. 기초이론 & 알고리즘 용어 (基礎理論・アルゴリズム)

| 일본어 표기                     | 요미가나 (발음)              | 한국어 의미 / 영문            | 시험 핵심 포인트                                                             |
| :------------------------------ | :--------------------------- | :---------------------------- | :--------------------------------------------------------------------------- |
| **基数変換**                    | きすうへんかん               | 기수 변환 (진법 변환)         | 2진수 $\leftrightarrow$ 10진수 $\leftrightarrow$ 16진수 변환                 |
| **2の補数**                     | にのほすう                   | 2의 보수 (Two's Complement)   | 비트 반전(1의 보수) 후 $+1$, 음수 표현 방식                                  |
| **浮動小数点数**                | ふどうしょうすうてんすう     | 부동소수점수 (Floating Point) | 부호(1비트) + 지수부(指数部) + 가수부(仮数部)                                |
| **論理シフト / 算術シフト**     | ろんり / さんじゅつシフト    | 논리 시프트 / 산술 시프트     | 산술 우시프트 시 빈자리는 부호 비트(MSB)로 채움                              |
| **排他的論理和**                | はいたてきろんりわ           | 배타적 논리합 (XOR)           | 두 비트가 서로 다를 때 `1`, 같을 때 `0` (특정 비트 반전에 사용)              |
| **逆ポーランド表記法**          | ぎゃくポーランドひょうきほう | 역폴란드 표기법 (후위 표기법) | 연산자를 피연산자 뒤에 표기 (`AB+`), 스택(Stack)으로 계산                    |
| **待ち行列**                    | まちぎょうれつ               | 대기행렬 (Queueing Theory)    | $M/M/1$ 모델의 평균 대기 시간 $\frac{\rho}{1-\rho} \times \text{서비스시간}$ |
| **単方向リスト / 双方向リスト** | たんほうこう / そうほうこう  | 단방향 / 양방향 연결 리스트   | 포인터(참조)를 이용한 노드 삽입·삭제 추적 (과목 B 단골)                      |
| **二分探索木**                  | にぶんたんさくぎ             | 이진 탐색 트리 (BST)          | 왼쪽 자식 $<$ 부모 $<$ 오른쪽 자식 성질을 만족하는 트리                      |
| **再帰呼出し**                  | さいきよびだし               | 재귀 호출 (Recursion)         | 함수 내부에서 자기 자신을 다시 호출하는 구조                                 |

## 3. 컴퓨터 시스템 & 아키텍처 용어 (コンピュータシステム)

| 일본어 표기                       | 요미가나 (발음)               | 한국어 의미 / 영문                  | 시험 핵심 포인트                                                                          |
| :-------------------------------- | :---------------------------- | :---------------------------------- | :---------------------------------------------------------------------------------------- |
| **主記憶装置 / 補助記憶装置**     | しゅきおく / ほじょきおく     | 주기억장치(RAM) / 보조기억장치      | 캐시 메모리와 주기억장치 사이의 실효 액세스 시간 계산                                     |
| **実効アクセス時間**              | じっこうアクセスじかん        | 실효 액세스 시간                    | $(\text{캐시 시간} \times \text{히트율}) + \text{주기억 시간} \times (1 - \text{히트율})$ |
| **割込み**                        | わりこみ                      | 인터럽트 (Interrupt)                | 내부 인터럽트(타이머, SVC 등) vs 외부 인터럽트(I/O, 전원 등)                              |
| **仮想記憶**                      | かそうきおく                  | 가상 기억장치 (Virtual Memory)      | 페이징(ページング), 페이지 폴트, LRU 페이지 교체 알고리즘                                 |
| **稼働率**                        | かどうりつ                    | 가동률 (Availability)               | $\frac{MTBF}{MTBF + MTTR}$, 직렬($A_1 \times A_2$) vs 병렬($1 - (1-A_1)(1-A_2)$)          |
| **デュプレックスシステム**        | デュプレックスシステム        | 듀플렉스 시스템 (Duplex)            | 주계(現用系)와 종계(待機系) 구성. 콜드/웜/핫 스탠바이 구분                                |
| **デュアルシステム**              | デュアルシステム              | 듀얼 시스템 (Dual)                  | 두 시스템이 동일한 처리를 동시 수행하고 결과를 상호 크로스 체크                           |
| **ストライピング / ミラーリング** | ストライピング / ミラーリング | 스트라이핑(RAID 0) / 미러링(RAID 1) | RAID 5는 패리티 분산 저장(최소 3대 디스크 필요)                                           |

## 4. 데이터베이스, 네트워크 & 보안 용어 (技術要素)

| 일본어 표기                 | 요미가나 (발음)                | 한국어 의미 / 영문           | 시험 핵심 포인트                                                                                                     |
| :-------------------------- | :----------------------------- | :--------------------------- | :------------------------------------------------------------------------------------------------------------------- |
| **主キー / 外部キー**       | しゅキー / がいぶキー          | 기본키 (PK) / 외래키 (FK)    | 개체 무결성 및 참조 무결성(参照制約) 제약조건                                                                        |
| **関数従属 / 正規化**       | かんすうじゅうぞく / せいきか  | 함수 종속 / 정규화           | 부분 함수 종속 제거(2NF), 이행적 함수 종속(推移的関数従属) 제거(3NF)                                                 |
| **排他制御 / デッドロック** | はいたせいぎょ / デッドロック  | 배타 제어(락) / 교착 상태    | 공유 락(共有ロック)과 전유/배타 락(専有ロック), 2상 로킹 규약                                                        |
| **公開鍵 / 秘密鍵**         | こうかいかぎ / ひみつかぎ      | 공개키 / 개인키(비밀키)      | 일본에서는 비대칭키의 개인키(Private Key)를 **秘密鍵**라 부르고, 대칭키는 **共通鍵(공통키)**라고 부름에 각별히 주의! |
| **共通鍵暗号方式**          | きょうつうかぎあんごうほうしき | 대칭키(공통키) 암호 방식     | 암호화와 복호화에 동일한 키 사용 (AES 등). 한국어의 '비밀키'와 혼동 금지                                             |
| **ディジタル署名**          | ディジタルしょめい             | 디지털 서명 (전자서명)       | 발신자의 **비밀키(개인키)**로 서명 생성, 발신자의 **공개키**로 검증                                                  |
| **耐タンパ性**              | たいタンパせい                 | 내탬퍼성 (Tamper Resistance) | 하드웨어나 소프트웨어 내부의 암호키·로직을 외부에서 물리적으로 분석·위변조하기 어렵게 만든 성질                      |

> **가장 많이 틀리는 한자 함정**: 한국에서는 대칭키를 '비밀키(Secret Key)', 비대칭키를
> '공개키/개인키(Private Key)'로 번역하지만, 일본 FE 시험에서는 대칭키를 **공통키(共通鍵)**,
> 비대칭키의 개인키(Private Key)를 **비밀키(秘密鍵)**라고 표기합니다. {: .prompt-danger }

## 5. 매니지먼트 & 스트래티지 용어 (マネジメント・ストラテジ)

| 일본어 표기                     | 요미가나 (발음)                       | 한국어 의미 / 영문                | 시험 핵심 포인트                                                                         |
| :------------------------------ | :------------------------------------ | :-------------------------------- | :--------------------------------------------------------------------------------------- |
| **結合テスト / 単体テスト**     | けつごう / たんたいテスト             | 결합(통합) 테스트 / 단위 테스트   | 상향식 테스트는 드라이버(ドライバ), 하향식 테스트는 스텁(スタブ) 사용                    |
| **退行テスト (レグレッション)** | たいこうテスト                        | 회귀 테스트 (Regression Test)     | 프로그램 수정 후 기존 정상 기능에 부작용(버그)이 없는지 재검증                           |
| **損益分岐点売上高**            | そんえきぶんきてんうりあげだか        | 손익분기점(BEP) 매출액            | $\text{고정비} \div (1 - \text{변동비율}) = \text{고정비} \div \text{한계이익률}$        |
| **貸借対照表 / 損益計算書**     | たいしゃくたいしょうひょう / そんえき | 대차대조표(B/S) / 손익계산서(P/L) | 자산 = 부채 + 순자산(자기자본), 매출총이익 $\rightarrow$ 영업이익 $\rightarrow$ 경상이익 |
| **請負契約 / 派遣契約**         | うけおい / はけんけいやく             | 도급 계약 / 파견 계약             | 도급 계약에서 고객사가 개발자에게 직접 지휘명령을 내리면 **위장도급(偽装請負)**          |
| **情報提供依頼書 / 提案依頼書** | じょうほうていきょう / ていあん       | RFI / RFP                         | RFI(정보 수집) $\rightarrow$ RFP(구체적 제안서 및 견적 요청) 순서                        |
